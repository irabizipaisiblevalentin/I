# I FAQ

## General

### What is I?

I is a compiled programming language with Kinyarwanda keywords, designed to make
professional programming approachable for African developers while remaining suitable
for serious software. It compiles to bytecode that runs on a built-in virtual machine.

### Who created I?

**Irabizi Paisible Valentin** (Rwanda). I is licensed under the MIT license.

### Is I production-ready?

Version 1.0.0 is the first stable release. The toolchain — compiler, VM, package
manager — passes a 4,000+ test suite and ships as a Production/Stable PyPI classifier.
Some advanced language features (logical operators, struct instantiation, loop
`continue`) are still on the roadmap; see the Language Guide's Known Limitations.

## Installation

### Which Python version do I need?

Python 3.10 or newer. 1.0.0 is tested on Python 3.14.

### `i` is not recognized as a command

The console script may not be on PATH. Either reinstall (`python -m pip install -e .`)
or invoke the module directly: `python -m compiler.compiler hello.i -r`.

### The compiler prints a RuntimeWarning about 'compiler.compiler'

It is cosmetic and comes from `python -m compiler.compiler`. Use the `i` entry point
to avoid it.

## Language

### Why does the README show `a kandi b` but it errors?

`kandi` (and) and `cyangwa` (or) are declared keywords but the 1.0.0 code generator
does not yet emit instructions for them. Combine conditions with nested `niba` blocks.
The README will be corrected to match the implemented language.

### Is the loop end inclusive?

No. `kuri i muri 0 kugeza 10` produces `0,1,2,...,9`. The end value is exclusive.

### What does `kugeza` mean in a loop?

`kugeza` (until) is a do-while loop: the body runs first, then the condition is
checked.

### What types exist?

`int`, `float`, `string`, `bool`, `null`, and lists (`urutonde`). Type annotations
are supported on function parameters and return types.

### Can I use the standard library from an I program?

In 1.0.0 the `shyiramo` import system resolves a small set of module names. The 44
`stdlib` modules are Python-hosted and are imported from host code with
`import stdlib.<name>`. See the [Language Guide](language-guide.md#modules).

## Toolchain

### How do I run a program?

```bash
i hello.i -r
```

### How do I see the generated bytecode?

```bash
i hello.i -d
```

### What is `isoko`?

`isoko` is the package manager: `python -m isoko.cli new`, `build`, `run`, `test`,
`publish`, and more. See the [isoko Guide](isoko-package-manager.md).

### Are there editor tools?

The `istudio` package provides editor engine primitives (debugger, editor config,
collaboration), and `uam` provides build configuration. A full IDE is on the roadmap.

## Ecosystem

### How do I publish a package?

Login with `python -m isoko.cli login`, then `python -m isoko.cli publish --dry-run`
followed by `python -m isoko.cli publish`. Full checklist in the isoko guide.

### Does I have a package registry?

The `isoko` registry client and protocol exist (login, search, publish, install). A
public hosted registry is part of the Sprint 4 release infrastructure.

## Security

### Is my login token stored securely?

Yes. Tokens are stored with owner-only permissions (`0600`), and the security report
documents the hardening applied.

### Does the standard library have security foot-guns?

Archive extraction rejects path traversal and symlinks; MD5/SHA-1 are marked
`usedforsecurity=False`; the process module is documented as launching host commands.
